# 织影 Atelier 下载

此仓库仅提供安装包、更新文件和下载说明。项目源码仓库保持私有，不在这里发布。

[下载最新版本](https://github.com/waltertech/zhiying-atelier-downloads/releases/latest)

- Mac：Apple Silicon（M 系列），下载 `.dmg`。
- Windows：64 位，下载 `.exe`。
- 更新到 0.2.1 需要先手动安装。此版本使用本仓库作为后续更新地址。
- Windows 提示更新后，可确认下载并重启安装；Mac 当前未签名，提示新版本后需下载并手动安装。
- 安装包不包含用户的 API Key、项目记录或上传素材，请在工作台设置中自行配置模型平台 Key。

发布文件中的 `.yml` 和 `.blockmap` 用于客户端更新，不需要手动下载。
